# 报告结构模板

写报告时照这个骨架填。每一节的标题可以直接用，也可以按题目改得更贴合内容。

```markdown
# <题目>调研报告

## 一句话结论

一两句话说清最重要的结论，不要铺垫。

## 它是什么

分条写，每条一句话，关键结论后标来源编号，例如 [1]。

## 怎么用 / 关键细节

给出可操作的信息：安装、核心 API、参数、典型用法。能给代码片段就给。

## 适用场景与注意事项

什么情况下合适、什么情况下不合适、有什么坑。

## 备注与不确定项

- 哪些结论只找到单一来源
- 哪些页面没抓到、因此没能核对
- 哪些细节依赖版本，需要读者自行确认

## 来源链接

1. <标题> — <完整链接>
2. <标题> — <完整链接>
```

## 硬要求

- 结论要能指回来源编号，报告最后必须列全链接。
- 抓取失败的来源也要列出来，并在"不确定项"里说明，别悄悄删掉。
- 长度按题目定，不要为了凑字数把摘要重复两遍。
